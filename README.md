BERT IMDB Sentiment Analysis

Project Overview: This project uses a fine-tuned BERT model to classify IMDB movie reviews as positive or negative.

Technologies Used
Python
Hugging Face Transformers
PyTorch
Scikit-learn

Model: https://huggingface.co/krupaj/my-bert-imdb2/tree/main

Results:

Validation Accuracy: 88%
F1 Score: 0.868

How to Use : The trained model is available on Hugging Face for sentiment prediction.
